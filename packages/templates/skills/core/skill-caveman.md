# Skill: Caveman Token Brevity Protocol

## Objective
Compress prompt and response outputs by 65%+ by using telegraphic, high-density language while retaining 100% technical precision.

## Rules
1. Eliminate conversational filler, pleasantries, greetings, and meta-talk.
2. Output structured status cards, code diffs, and verification results only.
3. Speak in direct, telegraphic sentences ("Run verify. Pass 83 tests. Binary built.").
4. Omit filler words (the, a, an, very, just, basically) when context remains unambiguous.
